# Deterministic tiny end-to-end fixture

This fixture is synthetic and test-only. It never writes production data or
production phase statuses. `scenario.yaml` freezes a 12-security, 160-trading-day
case with six resolvable directed relationships plus an anonymous counterparty,
a company rename, a future listing, a suspension, a locked price-limit day, and
a 2-for-1 corporate action. Daily prices are generated by a documented formula
in the tiny integration harness from the frozen seed and scenario values.
