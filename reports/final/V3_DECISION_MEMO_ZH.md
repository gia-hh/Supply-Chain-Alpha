# V3 去留决策备忘录：本地数据零增长方案

## 决策前提

- V2 永久保留为 `PATH_B_DATA_INFEASIBILITY`，不得通过修改门槛、延长边寿命或补合成边改写。
- 新增本地原始数据量固定为 **0**。现有约 115.66 GiB 原始语料不再扩张。
- V3 只在独立版本、独立规则哈希和独立实验注册下开展。
- 在新的真实覆盖门槛前，不读取收益、构造 IC、选择持有期或运行生产回测。

## 当前需要跨越的数量级

- 最佳年份只有 116 条年末活跃边，距 200 条门槛差 84 条，需要在最佳观测值上增加 72.41%。
- 2016—2022 年可用年份为 0；目标不是改善某一个年份，而是形成至少 3 个连续可用年份。
- 35,801 个未解析审计键是可在现有产物上继续研究的主要候选池。
- 只有 23 / 30,126 份文档为 `NO_TEXT`；全面 OCR 不是优先投资方向。

## Gate 0：先估计可恢复覆盖的理论上限

### 预注册抽样

从现有未解析审计键中抽取首轮 600 个样本，不重新下载 PDF。按以下维度分层：

1. 年份；
2. 规范化名称出现频率；
3. 企业后缀与名称长度；
4. 客户/供应商角色；
5. 表格噪声、OCR 噪声和普通文本。

600 个独立 Bernoulli 观测在最不利比例附近的 Wilson 95% 半宽约为 4 个百分点。实际记录存在名称和文档聚类，因此最终区间必须使用分层权重并以名称/文档为簇进行 bootstrap；不得把普通 Wilson 区间当成严格总体区间。

### 盲法标签

在查看任何收益前，将样本标为：

- 可依据现有证据安全映射到上市主体；
- 私营、境外、政府或其他非上市实体；
- 集团/子公司，不能无证据映射到上市母公司；
- 名称歧义；
- 版面或 OCR 噪声；
- 仍需外部权威证据。

两名标注者独立处理重叠子样本，报告原始一致率和 Cohen's kappa。争议项保持未解析，不以协商结果追求覆盖率。

### 覆盖上限模拟

把各层“可安全恢复”的比例及其不确定性投影回年度候选池，并重新执行去重、上市区间、发布日期和 550 日边龄约束。输出每年的活跃边、连接股票以及所有连续三年窗口的区间，而不是只推算总名称数。

决策规则：

- **STOP**：即使使用 95% 乐观上界，所有连续三年窗口仍无法满足原覆盖门槛；
- **PROCEED**：95% 保守下界已满足连续三年门槛、可用年份连接股票中位数门槛及全部零容忍完整性检查；
- **EXPAND PILOT**：区间跨越门槛时扩大盲法样本，不进入收益研究。

## Gate 1：只优化现有语料的高价值环节

按预期新增“安全、唯一、PIT 合法的上市边”排序，而不是按解析行数排序：

1. 修复高频表格模板、跨行单元格和异常空格；
2. 补充有权威时间证据的历史法定名称和简称；
3. 把集团、子公司和品牌关系作为独立实体层记录，只有存在有效期明确的控制关系时才投影到上市证券；
4. 对高频未解析名称做候选生成，但继续保留唯一性阈值、证据链和人工覆盖审计；
5. 采用增量分区重算，只重跑受规则变更影响的文档/名称键，不复制整套 PDF。

验收指标必须是年度 PIT 图覆盖增量和错误率，不是模糊匹配召回率。已接受映射的盲审精度、时间穿越、匿名映射、来源缺失和重复暴露仍为零容忍门槛。

## Gate 2：远端预筛，避免本地扩容

若现有语料上限不足，只允许在远端对象存储、数据仓库或有许可的数据供应商环境中进行覆盖预筛：

- 原始文件、企业层级全表和大规模中间表留在远端；
- 本地只接收版本号、查询参数、来源许可证标识、哈希、聚合覆盖统计和通过审计的派生边；
- 先计算每年能否跨越门槛，再决定是否建立 V3 数据合同；
- 远端来源也必须支持 PIT 有效期、可重放查询和逐边来源证据。

不能把“远端不落盘”理解为可以降低来源、授权、安全或复现要求。

## 若覆盖仍不足：改变问题，而不是改变答案

可另立研究问题，例如首次关系披露事件、高置信度子图或行业内案例研究。这些设计的外推对象是“主动披露且可识别的关系”，不能继续使用“完整 A 股供应链网络”的表述，也不能与 V2 共用结论标签。

## 未来经济识别要求

只有新覆盖 gate 通过后，才进入以下识别工作：

- PIT 行业、规模、风格和宏观共同因子；
- 目标自身滞后收益与历史相关网络 placebo；
- 反向边、同业边和匹配随机图 placebo；
- 披露选择模型与可观测选择敏感性分析；
- 新的冻结验证区间和未来 holdout。

这些方法能改善共同冲击与网络扩散的区分，但不能修复当前图覆盖，也不能证明因果关系。

## 明确禁止

- 看到结果后降低 200 边、150 股票、连续 3 年或中位数 200 股票的门槛；
- 为提高覆盖而延长 550 日边龄；
- 用合成、匿名或歧义实体补边；
- 无证据把子公司、集团或品牌强制归到上市公司；
- 以更多显著性检验替代数据可行性；
- 在新覆盖 gate 之前读取 holdout 或报告收益、IC、Sharpe、alpha、盈利性。

## 推荐的下一次人工决策点

只批准 Gate 0 的 600 条盲法上限审计。拿到按年度重建的覆盖区间后再决定 STOP、EXPAND PILOT 或 PROCEED；在此之前不增加本地原始数据，也不投入完整 V3 工程。
